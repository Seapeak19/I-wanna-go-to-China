# I wanna go to China

## 在线访问

**[🌏 点击访问 I wanna go to China →](https://seapeak19.github.io/I-wanna-go-to-China/)**

无需下载项目，点击上方链接即可在浏览器中打开网站。首页目录独立加载，全国搜索使用轻量索引；进入省份、打开详情或恢复跨省行程时，按需读取相关省份的完整资料。外语与繁体中文资料在选择对应语言时加载。卡片使用实景缩略图，详情使用较大展示图，并保留原始图片来源及出处。

一份面向中国旅行的实用指南，帮助你从省份、城市走进县城、古镇与小众目的地。通过景点资料、游客评价线索、实景照片和预算工具，把想去的地方整理成自己的旅行计划。

网站目录覆盖中国全部 34 个省级行政区，包含香港、澳门和台湾。内容按省份持续补充，各地资料深度不同，尚未收录全国所有景点和县域目的地。

## 主要功能

- **卡片探索首页**：按华南、华东等大区筛选，以省份卡片查看代表城市与实景照片，再逐级进入市州、区县。电脑侧栏与手机底部面板联动显示景点、美食及行程。区县目录采用注明版本的行政区快照，缺少准确攻略时如实标注待补充。

- **探索目的地**：按省份、城市、旅行主题和季节筛选，也可搜索中英文地名、景点与美食关键词。
- **查看景点攻略**：图片上展示已核对的门票价格或免费参观范围，未确认时明确标注待核实；详情保留票务来源、核对日期、交通、开放与预约提示、建议路线，以及同行和步行提醒。
- **参考游客体验**：查看带来源链接的评价摘要，区分个体体验、样本局限和需要再次确认的信息。
- **查看实景照片**：保留出处、原图及可确认的摄影者与拍摄日期，区分开放许可与原站版权；暂无核对后图片时展示文字封面。
- **美食攻略**：按地区、城市、参考人均、店名或菜品筛选门店，优先查看标有当地特色的地方菜与小吃，参考按片区安排的美食路线与编辑分餐建议，并把门店或整条路线加入餐饮清单。结合餐厅官方、携程、去哪儿、大众点评及B站公开视频简介，分别标明价格依据、历史体验、小样本局限与待复核事项。
- **多个行程与完整备份**：分别保存旅行计划，支持复制、命名、JSON备份导入及链接分享。导入先预览并创建新行程，保留手动改价、餐饮开关、每天安排与备注。分享链接携带预算和备注，不提供云端存储。
- **按天安排**：将景点和每次用餐分配到日期，填写时间与时长，查看常规闭馆日、时间重叠及行程过满提示。每天预算与整趟费用逐分对齐，地图链接用于外部核对路线，路程时间需自行确认。
- **独立攻略目录**：简体中文和英文的省份、城市与景点页面可直接阅读与分享，带来源、核实日期和搜索引擎入口；互动主站继续支持12种语言。
- **资料维护**：查看各省票务、开放依据和图片许可缺口，筛选开放许可图片。每日北京时间06:20计划更新参考汇率、轮换检查40条来源链接；任务可能延迟，失败保留原值及原日期。链接可访问不代表价格、评价或营业状态已核实。
- **对比与规划**：最多同时对比 3 个目的地；将景点加入行程，调整顺序和人数，自动带入已确认的单一门票，按需修改，再填写住宿、餐饮及交通，统一计算全员、人均整趟和人均每天预算，并导出或打印明细。

城市目录按“每城至少 8 个有来源的景点条目”逐省建设，8 个是最低收录标准，不是数量上限。结合城市规模、交通可达性与旅游需求分配更多条目，属于编辑判断，不是官方城市排名，景点会持续补充。待调研线索不计入最低数量，同一复合景区不拆分计数。广东与广西已开放地级市筛选，每市至少 8 个景点；北京、上海、重庆按直辖市设置统一城市选项，区县写入具体地点。详细攻略和名录基础资料分别标示，数量达标不表示票价、开放、评价与图片全部完成核实。

## 语言与货币

支持简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Italiano、Português、Nederlands 与 Русский，共 12 种语言，语言和货币可独立切换。新增外语攻略使用本地打包的机器译文，页面明确提示，不能替代原始来源；部分无法可靠处理的文字保留英文。保留中文地名、店名与原始来源，方便导航与核对。繁体中文使用 OpenCC 转换。

支持 CNY、USD、EUR、GBP、JPY、HKD、MOP、TWD、SGD、AUD、CAD、KRW、RUB，共 13 种货币。人民币为预算核算基准，切换货币时换算显示金额。参考汇率注明来源和日期，也可设置个人预算汇率。卢布使用所示日期的俄罗斯央行 CNY 报价；澳门元按澳门金融管理局公布的 1 HKD = 1.03 MOP 联系汇率及所示日期港币参考值交叉换算；新台币使用台湾银行人民币即期买入与卖出牌价的本站算术均值，页面保留来源及日期，并非银行提供的中间价或成交报价。其他外币使用所示日期的欧洲央行参考汇率，均非实时成交价。

## 如何使用

1. 选择地区，按季节和兴趣寻找目的地，再添加到行程。
2. 打开攻略，查看资料来源、费用依据与待确认事项。
3. 把感兴趣的地点加入对比或行程，调整游览顺序和停留时间。
4. 补充住宿、往返大交通及其他费用，导出计划，并在出发前复核开放、预约与交通安排。

## 预算与资料说明

消费统计自动带入已确认的单一门票（含免费），保留用户手动改价；港币、澳门元和新台币票价保留原币，预算按注明日期的参考汇率折算成人民币基准，可自行调整；分园区或多票种先选择，未核实价格留空。景点门票按单价 × 购票数量；住宿按每间每晚价格 × 房间数 × 晚数；其他餐饮及公交按人均每天计算；餐饮总费用为“自填其他餐饮＋已勾选美食店”，店铺费用按单次人均 × 用餐人数 × 次数计算。单独加入门店默认计费，整条路线的新店默认不计费，逐店勾选后计入。同一分店不重复添加，可调整价格、人数、次数、开关，并在餐饮项下展开已保存攻略、查看人均餐饮消费。参考价格区间或缺失价格需自行填写。打车、包车、城际交通、往返大交通和其他费用按全员整趟合计填写，共用费用只计算一次。空白为待填写，填 0 表示无支出；未填写时显示已填小计，不冒充完整预算。金额为预算，不代表实际已支付。

资料优先参考官方渠道，并结合公开游客页面。评价摘要保留可追溯入口，不伪造亲测、评分或消费凭证，也无法独立确认每位用户实际到访。历史价格、过期活动、信息冲突及未核实项目会分别标注。具体覆盖范围与收录规则可在网站“资料与更新”中查看。

照片优先参考景区、博物馆和文旅部门公开实景，并结合开放许可图库与公开平台。图片保留原站水印、出处及可确认的署名；原站版权图片不标为开放许可，转载授权未核实。原图和来源链接供查阅，使用者需要按原站规则另行确认转载权限。历史照片、图册和复合景区局部配图会在说明中标注，不能据此判断当前现场状态。

## 保存与离线使用

语言、货币、对比、行程、消费明细及自定义预算汇率保存在当前浏览器，没有账号或云同步。清除浏览器数据会删除本地计划，建议及时导出备份。

离线版内置攻略、英文内容、已收录照片和参考汇率，可在无网络时浏览和规划；外部来源、地图和预约服务仍需联网。资料与汇率不会自动刷新。

## 本地构建与检查

使用 Node.js 22 或以上版本及 Python 3.12。先执行 `python -m pip install -r scripts/requirements-images.txt` 安装图片构建依赖，再执行 `npm ci`、`npm run build`、`npm test`、`npm run check`。可用 `PYTHON` 环境变量指定 Python 解释器。构建产物位于 `dist/`，通过 HTTP 服务预览。

攻略以仓库中的 `data.json` 为来源，生成轻量全国索引、省份分片与卡片目录。构建自动生成最长边不超过 480 像素的列表图和 1280 像素的详情图，保留完整画面及来源信息，原始照片继续保存在仓库中。发布包只包含展示图片和分片资料，不重复发布完整原始数据文件。翻译资料仍按语言保存在 `i18n/`。GitHub Actions 会缓存生成图片、执行检查并部署构建产物。

维护方式与核实边界见 [维护说明](docs/maintenance.md)。
