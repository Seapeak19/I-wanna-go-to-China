# I wanna go to China

一份面向中国旅行的实用指南，帮助你从省份、城市走进县城、古镇与小众目的地。通过景点资料、游客评价线索、实景照片和预算工具，把想去的地方整理成自己的旅行计划。

网站目录覆盖中国全部 34 个省级行政区，包含香港、澳门和台湾。内容按省份持续补充，各地资料深度不同，尚未收录全国所有景点和县域目的地。

## 主要功能

- **探索目的地**：按地区、旅行主题、季节和每人每天预算筛选，也可搜索中英文地名、景点与美食关键词。
- **查看景点攻略**：了解交通、门票依据、开放与预约提示、建议路线，以及同行和步行提醒。
- **参考游客体验**：查看带来源链接的评价摘要，区分个体体验、样本局限和需要再次确认的信息。
- **查看实景照片**：保留摄影者、拍摄日期、许可与原文件链接；暂无可靠授权图片时展示文字封面。
- **寻找美食线索**：按地区、店名或菜品查看已收录的候选门店及价格依据，资料逐步补充。
- **对比与规划**：最多同时对比 3 个目的地；将景点加入行程，调整顺序、停留天数、人数与费用预留，并导出或打印计划。

## 语言与货币

支持简体中文与 English，语言和货币可独立切换。英文内容为网站整理资料的翻译，不代表原始来源提供官方英文版本。

支持 CNY、USD、EUR、GBP、JPY、HKD、SGD、AUD、CAD、KRW。人民币为预算核算基准，切换货币时换算显示金额。参考汇率注明来源和日期，也可设置个人预算汇率。

## 如何使用

1. 选择地区，按人数、季节、兴趣和预算寻找目的地。
2. 打开攻略，查看资料来源、费用依据与待确认事项。
3. 把感兴趣的地点加入对比或行程，调整游览顺序和停留时间。
4. 补充住宿、往返大交通及其他费用，导出计划，并在出发前复核开放、预约与交通安排。

## 预算与资料说明

目的地日预算为编辑规划估算，包含住宿、餐饮、当地交通和门票预留，往返大交通单列。门店与景区费用注明参考依据；预算和货币换算均不是实际预订或结算报价。

资料优先参考官方渠道，并结合公开游客页面。评价摘要保留可追溯入口，不伪造亲测、评分或消费凭证，也无法独立确认每位用户实际到访。历史价格、过期活动、信息冲突及未核实项目会分别标注。具体覆盖范围与收录规则可在网站“资料与更新”中查看。

## 保存与离线使用

语言、货币、对比、行程及自定义预算汇率保存在当前浏览器，没有账号或云同步。清除浏览器数据会删除本地计划，建议及时导出备份。

离线版内置攻略、英文内容、已收录照片和参考汇率，可在无网络时浏览和规划；外部来源、地图和预约服务仍需联网。资料与汇率不会自动刷新。
