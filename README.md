# I wanna go to China

中国旅行指南。支持简体中文 / English，覆盖目录、攻略摘要、餐厅候选、筛选、对比、行程与导出。支持中英文名称和菜品搜索。英文是网站整理内容的翻译，不代表原始来源提供了官方英文版本。

支持 CNY、USD、EUR、GBP、JPY、HKD、SGD、AUD、CAD、KRW。汇率为欧洲央行 2026-10-15 日参考汇率快照；并非实时汇率、银行结算价或商户报价。来源：https://www.ecb.europa.eu/stats/eurofxref/eurofxref-daily.xml 。可为所选币种设置个人预算汇率，也可恢复快照。汇率超过 7 天会显示时效提醒。数据不会自动联网刷新。

核算基准始终为人民币。切换货币转换显示金额和预算输入框，保留人民币原值；语言与货币互相独立。门店保留原始参考价格及其依据。行程导出包含显示币种、原始核算币种、所用汇率与日期。预算仍为编辑估算，不是实际预订价格。

语言、货币、行程和自定义预算汇率只保存在当前浏览器；无账号和云同步。旧版行程存储可继续使用。离线版已内置英文内容、照片和汇率，切换时不依赖第三方网络请求。资料覆盖范围、图片署名和局限请见网站“资料与更新”。

验证：在项目目录运行 `node --test tests/globalization.test.cjs`。单元测试涵盖货币往返换算、无效汇率、货币代码、英文内容和静态界面翻译覆盖；浏览器另检查交互与布局。

本仓库维持私有，尚未启用 GitHub Pages。本包不含账号凭据或原托管平台配置。

## 广东景点第 1 批（2026-10-16）

广东从 3 个条目扩充为 14 个景点，覆盖广州、深圳、江门、韶关、肇庆、东莞、湛江、阳江、惠州、潮州、清远、汕头 12 市。全国目录现有 113 个条目，34 个省级行政区保持完整。

本批包含陈家祠、白云山、大鹏所城、仙湖植物园、自力村碉楼、丹霞山、七星岩、可园、湖光岩、海陵岛、惠州西湖，并深化潮州古城、连南千年瑶寨、南澳岛。14 条均有中英文实用资料、来源链接及开放许可照片；其中 9 条有可追溯评价资料，其余明确标记尚未抽样。照片中的南澳大桥、弘法寺分别标明具体子地点。

门票与开放字段区分官方价格、历史参考、平台列示及未确认项。自力村页面的临时闭园冲突、湖光岩已过期的春节安排均明确提示，不能当作实时开园保证。路线和每天预算为编辑建议，不是逐段实测或商业报价。

这是首批更新，尚未覆盖广东全部 21 市和全部县域；餐饮门店及价格另批调研。仓库保持私有，不更改公开访问或部署设置。
