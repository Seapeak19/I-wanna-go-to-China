# Display font

journey-display.woff2 is a subset of NotoSerifCJKsc-Regular.otf (Noto Serif CJK SC Regular), sourced on 2026-10-25 from https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Regular.otf .
License: SIL Open Font License 1.1; see OFL-NotoSerifCJK.txt.
Subset contains code points used in index.html and interface-motion.js, plus U+0020–U+024F. Generated with FontTools; source remains unmodified outside subsetting and WOFF2 compression. Missing glyphs use the CSS fallback. Re-subset when display copy changes.
Existing photographic assets remain unchanged and retain their original data records and visible source links. No AI-generated scenery ships.
